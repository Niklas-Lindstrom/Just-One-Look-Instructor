# Just One Look

A simple, practical website for the Just One Look Method.

## What Is It?

The Just One Look Method is a simple observation exercise:

1. **Look at yourself** - Direct your attention toward the immediate feeling of being you.
2. **Practice attention** - Strengthen your ability to intentionally direct your focus.

That's it. Simple and direct.

## Pages

- **Home** (`index.html`) - Introduction and entry point
- **Do It** (`do-it.html`) - Step-by-step guide to the inward look
- **What Is It?** (`about.html`) - Explanation of the method
- **FAQ** (`faq.html`) - Common questions and answers

## Design Philosophy

- **Simple** - No unnecessary complexity
- **Direct** - Focused on doing the practice, not endlessly explaining it
- **Practical** - Grounded in actual observation
- **Non-mystical** - No spiritual language or grand claims
- **Ordinary** - Calm and straightforward

## Usage

1. Visit the home page
2. Click "Start Now" or "Do It"
3. Follow the step-by-step guide
4. Use the FAQ if you have questions
5. Return to "What Is It?" to learn more

## Getting Started

### Local Development

```bash
# Clone the repository
git clone https://github.com/Niklas-Lindstrom/Just-One-Look-Instructor.git

# Open in browser
open index.html

# Or use a local server (Python 3)
python -m http.server 8000
# Visit http://localhost:8000
```

### Deploy to GitHub Pages

1. Push changes to `main` branch
2. Go to repository Settings > Pages
3. Select `main` branch as source
4. Save
5. Site will be available at `https://username.github.io/Just-One-Look-Instructor/`
